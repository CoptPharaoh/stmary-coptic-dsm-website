# Parish administration

Open /admin/index.html and sign in with your personal invited account. Owners and administrators will be asked for an authenticator code. Choose Send password reset on the sign-in form when needed.

Choose Announcements, then Create draft. Enter the title, body, ministry, placement, and optional Arabic text. Save as draft while preparing it, or pending_review when ready for an authorized publisher. A publisher can open the item, select published, and save. The database checks this permission.

Publication and expiration fields use the computer or phone's local timezone, shown in their labels. Check the device timezone before scheduling. Published announcements appear on /announcements.html when assigned to the announcements placement and within their publication window.

Choose Events to create or edit a one-time event. Times are stored as absolute timestamps. Event administration currently stores records only. These records are not yet connected to the public parish calendar.

Use archived to remove an announcement from the active feed. Sign out when finished. Do not use a shared account.

Inviting servants, assigning ministry access, revoking access, and recovering ownership currently require the trusted Supabase setup process described in ADMIN_SETUP.md. The portal has no user-management screen yet.

Cancellation of an individual recurring service and changes to weekly schedules still use the existing reviewed parish schedule workflow. The live calendar management interface is pending.
